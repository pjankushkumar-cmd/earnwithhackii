# JAI CLUB BOT

## Setup

1. Open BotFather on Telegram
2. Create bot using /newbot
3. Copy bot token
4. Open api/bot.js

Replace:

YOUR_BOT_TOKEN
YOUR_ADMIN_CHAT_ID

5. Upload project to GitHub
6. Import project in Vercel
7. Deploy

## Webhook

Open browser:

https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook?url=YOUR_VERCEL_URL

Example:

https://api.telegram.org/bot123456/setWebhook?url=https://jai-club.vercel.app
